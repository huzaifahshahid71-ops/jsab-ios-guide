# Repository scope
Document the verified JSAB 1.6.50 port revision 3. Keep game binaries, assets,
IPAs, saves, provisioning profiles, credentials, private logs and local archives
outside this repository. Preserve upstream licenses and attribution. No DRM,
license, anti-tamper or store-client check bypasses. JSAB patch offsets are only
for the inspected engine and must never be applied to another game. Check guards
and device evidence before claiming a fix. The rebuild runner operates on private
staging inputs and defaults to no device installation. Do not promise a clean
from-original build until that workflow has been independently reproduced.
